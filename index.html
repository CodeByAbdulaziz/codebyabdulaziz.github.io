Saudi RetailPulseDATA ANALYSIS

PROJECT 01 / DATA

Saudi RetailPulse

Explore Saudi point-of-sale payments in SAR. This project brings monthly trends, sector and city results, and forecast comparisons into one dashboard.

  • Python
  • SQL
  • Streamlit
  • pandas
View project on GitHub
A closer look +

I checked the data before analysis and compared simple forecasts with gradient boosting. The same-month-last-year method performed best, with a test WAPE of 5.65%.

Source: Saudi Central Bank point-of-sale data, shared through KAPSARC.

PROJECT 02 / IoT

Smart Energy Monitor

Track power readings and energy use with a web dashboard. Connect an ESP32 through MQTT or try demo mode without hardware.

  • React
  • FastAPI
  • PostgreSQL
  • MQTT
View project on GitHub
A closer look +

The project includes usage history, alerts, relay controls, and estimated energy cost. It connects a Python backend to a React dashboard and supports ESP32 integration.

Demo mode uses sample readings. The 24-hour forecast uses historical hourly averages.
